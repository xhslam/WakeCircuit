# 醒醒闹钟（WakeCircuit）

**醒醒闹钟**是一款面向 Android 15 的原生任务闹钟。闹钟在设定时间响起后，用户必须依次完成高数题、联网识图拍摄与英语跟读三项挑战，应用才会停止前台播放的铃声。

> 这是一份用于个人测试的 **Debug APK**。首次安装 Android 可能会要求允许“从此来源安装未知应用”。

## 已实现的能力

| 模块 | 当前行为 |
| --- | --- |
| 定时唤醒 | 以系统闹钟方式设置每日单个闹钟，并在设备重启后尝试恢复。 |
| 持续响铃 | 通过前台播放服务循环播放所选系统铃声；任务完成前没有应用内“跳过”入口。 |
| 数学任务 | 每次响铃随机生成一道高等数学基础题，覆盖导数、定积分、极限和偏导数。 |
| 随机拍摄 | 随机要求拍摄常见物品；照片在提交时发送给用户配置的联网视觉服务进行核验。 |
| 英语跟读 | 使用设备的英语语音识别服务转写，并按文本相似度评分；达到 **78%** 即通过。 |
| 铃声设置 | 调用 Android 系统铃声选择器，支持选择设备上的闹钟铃声。 |
| 隐私处理 | 联网识图密钥保存于 Android Keystore 支持的加密偏好存储；照片只在当前核验时发送。 |

## 安装

请将 `app-debug.apk` 传到 Android 15 手机后打开并安装。安装完成后按下列顺序完成准备工作。

| 步骤 | 操作 | 原因 |
| --- | --- | --- |
| 1 | 进入“首次使用准备”，授予**相机、麦克风、通知**权限。 | 拍照任务、英语跟读与响铃通知均需要这些授权。 |
| 2 | 点击“检查精确闹钟权限”。 | 确保系统可以在设定时间精确调度闹钟。 |
| 3 | 点击“允许锁屏全屏响铃”。 | 让闹钟可在锁屏或息屏时呈现全屏任务界面。 |
| 4 | 打开右上角设置，配置联网识图服务。 | 随机拍摄任务必须联网核验，未配置时不会放行。 |
| 5 | 选择铃声、设置时间，并打开“每日唤醒”。 | 应用会将下一次闹钟注册到系统。 |

## 联网识图配置

“联网识图”页面默认展示一个兼容 Chat Completions 图片输入格式的服务地址示例。你需要自行提供视觉服务的 **API 密钥** 与可用的 **视觉模型** 名称。应用会将一张压缩后的挑战照片连同严格的核验说明发送至 `服务地址/chat/completions`；服务必须返回如下 JSON 结构：

```json
{"match": true, "reason": "目标物品清晰可见"}
```

配置常见兼容服务时，请确认服务支持多模态 `image_url` 输入与 JSON 文本输出。不要将 API 密钥截图、分享或提交到公开仓库。

## 建议测试流程

先将闹钟设置到当前时间后 2–3 分钟，再锁屏等待触发。完成高数题后，用后置相机拍下要求物品；识图通过后按页面句子跟读英文。三个步骤全部通过后，应用会显示“全部完成”并停止铃声。

| 需要核验的点 | 预期结果 |
| --- | --- |
| 息屏触发 | 铃声启动，并出现前台闹钟通知或全屏任务页面。 |
| 高数题 | 错误答案展示提示；正确答案立即进入拍摄。 |
| 拍摄任务 | 未拍到指定物品时不放行；识别成功后进入跟读。 |
| 英语跟读 | 识别相似度低于 78% 时允许重试；达到门槛后结束任务。 |
| 重启手机 | 手机重启后，已启用闹钟会被重新注册。 |

## Android 15 注意事项

系统将精确闹钟与全屏通知视为需要用户明确许可的能力。闹钟类应用应在用户授权后调用系统精确闹钟接口；全屏通知权限也可在系统“特殊应用权限”中被关闭。因此，若闹钟未按时显示，请优先回到应用的“首次使用准备”页面检查两项授权。[1] [2]

即使应用中不提供跳过按钮，Android 仍允许用户通过系统级的强行停止、卸载、静音或权限撤销来中断应用；这是平台安全机制，第三方应用不应绕过。
